# 🥚 AVICONTROL - Sistema de Gestión Avícola

Sistema web para la gestión integral de producción y venta de huevos. Desarrollado con Django + GraphQL + React.

## 🚀 Tecnologías

**Backend:**
- Django (Framework web)
- Strawberry GraphQL (API)
- PostgreSQL (Base de datos)
- JWT (Autenticación)

**Frontend:**
- React 19 + Vite
- TailwindCSS 4
- Apollo Client 4
- React Router 7

## 📋 Funcionalidades

- ✅ Autenticación con JWT y rutas protegidas
- ✅ CRUD de Clientes
- ✅ CRUD de Lotes, Granjas y Galpones
- ✅ CRUD de Insumos (con alertas de stock mínimo)
- ✅ Registro diario de Producción de huevos
- ✅ Registro de Pedidos (con control de stock)
- ✅ Registro de Ventas (descuenta stock y cambia estado)
- ✅ Dashboard con métricas en tiempo real
